# My-Doc | Base de Conhecimento Técnico

> Repositório dedicado ao registro, documentação e consolidação de estudos nas áreas de **Cibersegurança**, **Redes de Computadores** e **Desenvolvimento de Software**.

---

## 📌 Sobre o Projeto

O **My-Doc** é uma base de conhecimento pessoal mantida de forma contínua. Seu principal objetivo é documentar conceitos, comandos, arquiteturas e práticas técnicas utilizando uma didática própria, clara e direta. 

Todas as anotações são sintetizadas com base em estudos práticos e teóricos, servindo tanto para consulta rápida no dia a dia quanto para a fixação de conteúdos complexos.

---

## 🗂️ Estrutura de Conteúdo

O repositório é organizado de forma modular, cobrindo os seguintes eixos temáticos:

*   🌐 **Redes de Computadores:** Protocolos, endereçamento IP, topologias, análise de tráfego e infraestrutura.
*   🐧 **Linux & Sistemas de Arquivos:** Comandos essenciais, administração de sistemas, permissões e estrutura de diretórios.
*   🏢 **Active Directory (AD):** Arquitetura de domínios, GPOs, autenticação (Kerberos/NTLM), enumeração e segurança em ambientes Windows.
*   💻 **Programação & Scripting:** Automação, desenvolvimento de ferramentas e lógica aplicada à segurança ofensiva/defensiva.
